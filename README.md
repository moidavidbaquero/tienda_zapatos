# UrbanStep - Tienda de zapatos frontend

# Realizado por:

Moisés David Baquero Daza

Proyecto realizado únicamente con HTML5, CSS3 y JavaScript Vanilla.

## Uso

1. Descomprime el proyecto.
2. Abre `index.html` en un navegador moderno.
3. Para una experiencia más estable con imágenes remotas, usa un servidor estático local (por ejemplo, Live Server), aunque el proyecto no necesita Node.js ni backend.

## Imágenes

Las imágenes de demostración usan URLs públicas de Unsplash. Si prefieres trabajar sin internet, reemplaza las URLs `imagen` de `js/productos.js` por rutas locales como `img/productos/tenis-urban.jpg`.

## Persistencia

LocalStorage guarda carrito, favoritos, usuarios de demostración, sesión y datos básicos del checkout.

## Seguridad

El login/registro es exclusivamente demostrativo. Nunca almacenes contraseñas así en producción. Un sistema real requiere backend, hash seguro de contraseñas, sesiones/tokens, validación del servidor y protección de datos.
